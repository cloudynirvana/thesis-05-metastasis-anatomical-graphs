```text
Knowledge ≠ Evidence ≠ Mechanism ≠ Parameter ≠ Prediction
```

A local tumour-burden ODE is not an anatomical graph. A lumped output is
not an identified transition matrix.

## Problem (one line)

Does a local tumour-burden ODE remain adequate once dissemination is an
organ-graph process, or do graph observables remain unidentified under
current lumped outputs?
